# UX Guidelines

- Dark-first, high-contrast UI inspired by Dokploy's restrained admin-console aesthetic.
- Purple is reserved for primary action/progress, green for healthy, amber for warning, red for failure/destructive.
- Avoid dense desktop tables on phone; use cards, expandable groups and bottom sheets.
- Long-press/overflow menus expose quick actions.
- Logs use monospace, search, time-range filters and a jump-to-live affordance.
- Keep the first screen operational: health, deployments, attention, quick actions.

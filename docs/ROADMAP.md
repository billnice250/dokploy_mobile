# Product Roadmap

## Product principle

Do not clone every Dokploy setting. Optimize for the moments when someone reaches for a phone: check health, understand a failure, inspect logs, redeploy, recover, and leave.

## North-star workflow

**Push notification → failed deployment → relevant logs → previous successful deployment → redeploy/rollback** in under 30 seconds.

## Phase 1: usable daily driver

Dashboard, projects, services, deployments, logs, start/stop/redeploy, server health, multi-instance and secure keys.

## Phase 2: operations

Compose service details, databases, backup/restore, scheduled jobs, domains, metrics, environment config, rollback.

## Phase 3: mobile-native

Push, biometrics, terminal, widgets, Siri/Android actions, offline cache, Git context, “backup then redeploy.”

## Phase 4: ecosystem quality

Compatibility CI, release matrix, telemetry-free diagnostics bundle, tablet UI, localization, store publication.
